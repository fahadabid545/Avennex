# Project Rules

## Communication
- Be concise. No unnecessary explanations.
- Report only what's asked.
- No filler phrases.

## Git
- Never use "Claude", "AI", "made with Claude", "generated" in branch names, commit messages, or comments.
- Commit messages: short, descriptive, human-written style (e.g., "fix header nav links", "add careers page structure")
- Branch naming: feature/[name], fix/[name], cleanup/[name]

## Code
- No code comments explaining obvious things.
- No "generated by" or "created by AI" comments anywhere.
- Keep files modular -- isolated but connected.
- FastAPI backend with Supabase PostgreSQL.

## Workflow
- One task at a time.
- Don't touch files outside the current task scope.
- Always confirm before deleting anything.
