# Avennex

Product studio building AI-powered tools that automate complex workflows.

## Tech Stack

- **Frontend:** Static HTML / CSS / JS, hosted on cPanel
- **Backend:** FastAPI + Supabase PostgreSQL (separate repo)
- **Admin:** Lightweight frontend, same API (separate repo)

## Structure

```
avennex/
  index.html          Homepage
  products.html       Current products
  roadmap.html        Future products and timelines
  blog.html           Blog listing
  blog-post.html      Blog detail template
  careers.html        Careers listing
  job-post.html       Job detail template
  about.html          About us
  contact.html        Contact form
  privacy.html        Privacy policy
  404.html            Not found page
  css/                Stylesheets (modular)
  js/                 Scripts (modular)
  img/                Images and icons
  fonts/              Self-hosted fonts (if needed)
```
